# Vocabulary Pro

Учебное приложение для английской лексики. Рабочая ветка coursework. Фронтенд использует HTML, CSS и чистый JavaScript с ES-модулями.

- Личный словарь и расписание хранятся в браузере. Изменения словаря проходят через js/storage.js. Правила модели и миграции находятся в js/model.js.
- Сохраняй стабильные ID слов и значений. Прогресс принадлежит значению. Проверяй совместимость со старым массивом myWords и с экспортом.
- Не очищай реальный localStorage при разработке и проверках. Для тестов используй синтетические данные и отдельный origin или имитацию хранилища.
- words.json служит каталогом Random Words. Python-бэкенд кластеризует только английские записи из личного словаря, переданные по явному действию пользователя. Прогресс и журнал в запрос не входят.
- Сохраняй чужие изменения в рабочем дереве. Не создавай коммиты и не отправляй их без разрешения.
- Запускай тесты командой node --test. Инструкция локального запуска и правила восстановления описаны в README.md.

- При внутреннем рефакторинге сохраняй существующую функциональность, визуальные элементы и пользовательские сценарии. Существенные изменения интерфейса требуют отдельного согласования.
