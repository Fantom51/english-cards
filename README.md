# Vocabulary Pro

Веб-приложение для изучения английской лексики. Библиотека, карточки, интервальное повторение, правописание, статистика и Random Words работают во фронтенде на HTML, CSS и чистом JavaScript. Раздел «Кластеры» использует локальный FastAPI и модель all-MiniLM-L6-v2 на CPU. Для запуска словаря Python-бэкенд не нужен.

## Локальный запуск

Из корня проекта запустите статический сервер с Python 3.

```powershell
python -m http.server 8001 --bind 127.0.0.1
```

Откройте http://localhost:8001/ в современном браузере. Используйте localhost или HTTPS для записи через Web Locks. Прямое открытие index.html через file:// не подходит для модулей и загрузки каталога. Хранилище привязано к адресу, включая порт. Если старый словарь открыт на другом адресе, сначала экспортируйте данные с того адреса. Если там ещё доступна только старая версия, сохраните значения myWords и activityLog через DevTools как резервную копию. Старый массив myWords можно импортировать отдельно.

## Данные и восстановление

- В ключе myWords хранится объект версии 1 с массивами words и activity. У каждого слова и значения свой стабильный ID. Расписание принадлежит значению. words.json используется только в Random Words.
- Миграция читает старый массив myWords и журнал activityLog, проверяет форму записей, затем сохраняет исходные строки в vocabularyPro.migrationBackup до записи новой схемы. Существующие копии сохраняются, при необходимости создаются ключи с числовым суффиксом. Старый ключ activityLog остаётся в браузере.
- Валидные параметры расписания переносятся по полям. Для первого перевода применяются валидные поля слова, если совпадают перевод и часть речи и соответствующего валидного поля у значения нет. Остальные пробелы заполняются начальным состоянием: интервал и число повторов 0, коэффициент 2.5, срок в текущий локальный день. Сохранившиеся даты переносятся как есть. Старый журнал переносится без пересчёта, так как его записи могли маркироваться ошибочно.
- В библиотеке «Экспорт» скачивает словарь с расписаниями и журналом. «Импорт» принимает такой файл или старый массив слов, валидирует его и просит подтвердить замену. Исходные данные перед заменой сохраняются в vocabularyPro.recoveryBackup. Изменение словаря после выбора файла отменяет замену.
- Если чтение не удалось, «Скачать исходные данные» сохраняет текстовые снимки и копии для диагностики. Архив тоже можно импортировать, если его основной снимок валиден. Если он повреждён, извлеките одну из сохранённых копий из поля backups в отдельный JSON-файл и импортируйте её. Импорт снимка сохраняет журнал вместе со словарём. Если валидной копии нет, можно явно импортировать пустой словарь `{"version":1,"words":[],"activity":[]}`. Исходный повреждённый снимок будет сохранён перед заменой.
- Версия приложения использует общий Web Lock и читает актуальное состояние непосредственно перед каждой записью. Изменения словаря и журнала сохраняются одним вызовом setItem. Защита действует для вкладок этой версии на одном origin. Перед обновлением закройте вкладки старой версии. При отсутствии Web Locks запись отключена. Запись также может завершиться ошибкой из-за настроек браузера или исчерпания квоты. Освобождайте место только после сохранения копий.

## Проверки

Запустите `node --test` с Node.js 22 или новее. Тесты используют синтетические данные и имитацию Web Storage и Web Locks. Установка пакетов не требуется.

## MVP кластеризации

Команды выполняются из корня проекта в PowerShell с существующей .venv на Python 3.13.3. Версии пакетов зафиксированы в backend/requirements.txt.

Один раз с доступом в интернет загрузите зафиксированную ревизию all-MiniLM-L6-v2 в .venv/huggingface/hub и проверьте инференс на CPU.

```powershell
Remove-Item Env:HF_HUB_OFFLINE -ErrorAction SilentlyContinue
$env:HF_HUB_DISABLE_XET = '1'
.\.venv\Scripts\python.exe -B -m backend.embeddings
```

На демонстрации откройте два терминала. В первом запустите бэкенд с локальным кэшем.

```powershell
$env:HF_HUB_OFFLINE = '1'
$env:OMP_NUM_THREADS = '2'
$env:MKL_NUM_THREADS = '2'
.\.venv\Scripts\python.exe -B -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Во втором запустите статический сервер.

```powershell
.\.venv\Scripts\python.exe -B -m http.server 8001 --bind 127.0.0.1
```

Для демонстрации откройте http://127.0.0.1:8001/ в отдельном профиле браузера. Это позволяет импортировать demo-vocabulary.json через библиотеку без замены рабочего словаря. Откройте «Кластеры» и запустите расчёт с порогом 0.65. Можно повторить с 0.60 и сравнить разбиение. Возвращаемое время измеряется на сервере и включает загрузку модели при первом запросе процесса.

POST /api/cluster получает список entries с id и английским text и необязательный distance_threshold. Значения по умолчанию используют нормализованные эмбеддинги, косинусное расстояние и average linkage. Одиночные записи отображаются отдельно. API принимает до 500 записей и до 200 символов на поле. Браузер сопоставляет возвращённые ID с переводами из личного словаря. Каталог Random Words, переводы, прогресс и журнал на сервер не передаются.

Тесты бэкенда запускаются командой:

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s backend/tests
```

Модель использует только написание. Например, слово apple может оказаться в одной группе с компьютерной лексикой из-за ассоциации с компанией. Локальное время выполнения и разбиение зависят от порога и входных записей.
